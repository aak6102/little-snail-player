# 小蜗牛播放器 (LittleSnail Player)

> 基于 [Next Player](https://github.com/anilbeesetti/nextplayer) 修改的 Android 视频播放器，面向「家长希望孩子看视频时不能随便快进」的使用场景。

本项目是 [Next Player](https://github.com/anilbeesetti/nextplayer) 的衍生作品（fork / modification），在保留其全部基础播放能力的同时，加入了**防快进**机制，并提供断点续播、去除画中画等适配。

---

## 项目简介

- **一句话定位**：给孩子用的「不能快进、看一会儿要答一道英语题」的视频播放器。
- **许可**：与原项目一致，遵循 **GNU GPL-3.0**（详见 `LICENSE`）。
- **当前版本**：v1.17.0（`versionCode=32`）。`applicationId` 已改为自有包名 **`xyz.a709048.snailplayer`**（域名 709048.xyz 倒写），因此与官方 Next Player 完全隔离，可共存安装，也不存在冒名问题。`namespace` 仍保留原 Kotlin 包路径，不影响系统识别。自 v1.15.0 起支持「关于 → 检查更新」在线升级，版本发布在 `snail.709048.xyz/admin/releases`，App 启动后自动检测并提醒更新，详见 `output/CHANGELOG.md`。

### 学习答题锁（v1.1.0）

**开启方式（v1.4.0 起）**：设置 → 关于 → **连点版本号 7 次** → 进入「家长设置」。

这一页不在常规设置列表里，孩子看不到入口。之所以不再用「两位数乘法」当验证题：四年级孩子的心算水平已经覆盖两位数乘一位数，而继续加难度会连家长一起挡住——数学题的难度对双方是同步上升的，用算术当门禁只会两头折腾。真正有效的是三件事叠加：**入口不知道在哪**、**知道了也关不掉（延迟 24 小时生效）**、**关掉了家长看得见（设置页顶部留痕并可撤销）**。

家长设置页同时管理**快进限制**：可关闭节流，也可把冷却时长改成 1/2/5/10 分钟。这原本是硬编码的 2 分钟常亮限制，现在由家长决定。

**设计要点**

- **计时只算「真的在播」**：`isPlaying && STATE_READY` 时才累加，暂停、缓冲、切后台都不计时。因此挂着不看、反复拖进度条都刷不到时长。
- **拦截在 Service 层**：计时与暂停都放在 `PlayerService`，写在 Compose 层的话，切后台 / 锁屏 / 通知栏继续播都能绕过。
- **锁会落盘**：待答题状态写入 `study.json`，杀进程重进仍需作答。
- **三档脚手架，只用排除法**：答错 1 次把该选项划掉（不可再点），2 次再划掉一个（只剩两个），3 次才显示答案并放行。提示文案里**不出现任何答案线索**——早期版本在第 2 次答错时就显示「正确答案」，选义题更是在第 1 次就把中文释义念出来，等于把脚手架做成了送分。不设倒计时、不做惩罚性重复——卡死会让孩子把英语和痛苦绑定。
- **加题量而不是加频率（v1.2.0）**：中断成本是固定的（注意力从剧情拔出再重新接上），所以「10 分钟 2 题」和「5 分钟 1 题」每小时题量相同，但前者少打断一半的剧情。
- **多题时的第一题是热身题**：只从「已经答过」的词里挑，且连对越多越可能被选中，目标是秒答，先建立「我能过」的信心再进新词；本次已出过的词不重复出现——同一词在 1 分钟内再见一次靠工作记忆就能答对，正确率高但不进长期记忆。
- **横屏自适应**：横屏手机可视高度常常只有 360dp，竖排会把选项挤出屏幕，因此横屏改为左右分栏（题干在左、选项在右），并用纵向滚动兜底极小屏。
- **题库只存词不存题**：`app/src/main/assets/quiz/` 下按 `index.json` 清单组织词表，当前为课标二级 505 词（`kebiao_primary.json`）；题目由题型模板在运行时生成。干扰项严格按 `confusables`（易混词）→ 同语义场 tag（`animal` / `food` / `job`…）→ 全库分层选取，避免孩子靠常识排除。旧的 155 词与 PEP 四上词表已从清单下线，文件仍留在包内供老存档做进度迁移反查。
- **选题有优先级**：欠账词（硬优先）> 错题池（连对不足 3 次）> 新词 > 7 天未复习 > 已掌握，同一词轮换听音 / 选义 / 看图三种题型。
- **浮动解锁（v1.3.0）**：本轮全对 → 看满设定间隔；有答错 → 只解锁 5 分钟。答完先出结果页说明「这次能看多久」，而不是直接续播——没有可见后果，孩子学不到「认真答更划算」。间隔已经是 5 分钟时两档重合，设置页不再宣称「答错更短」。
- **欠账必答（v1.3.0）**：上一次没独立答对的词（含「错满三次看答案放行」）写入 `WordStat.debt`，下次拦截被强制抽中且压过热身题；揭示答案后不提供「我记住了」按钮，必须点中正确答案（此时另外三个选项已被划掉，所以不会形成新的卡死点）。答对即销账。
- **延迟关闭 + 留痕（v1.4.0）**：关闭学习模式不立即生效，而是排定在 24 小时后。`StudyPreferences.autoDisableAtMillis` 到期后**不清零**，它同时充当「最近一次被关掉」的证据——孩子就算摸进家长设置点了关闭，今天照常被拦，家长隔几天打开也能看到「已于 X 关闭」而不是一片空白。
- **按日归档（v1.5.0）**：原来只有 `dailyStats` 一格，换天清零，导致「近 7 天趋势」永远只有一个数据点。现在换天时把前一天收进 `dailyHistory`（key 为 `yyyy-MM-dd`，只留最近 14 天），今天仍读 `dailyStats`，两者职责不重叠，旧存档可直接兼容。记账逻辑抽成 `StudyProgress.withAnswer()` 纯函数，`LocalStudyRepository` 与 `FakeStudyRepository` 共用一份，避免只改一边。
- **进度主键是词面（v1.6.0）**：`wordStats` 的键从「词条 id」（如 `num_thirteen`）改成「词面小写」（如 `thirteen`）。id 是人编的，换一套教材词表就全变，切词表等于清空错题池；词面不变的是「同一个单词」，两套词表里拼写相同的词共享掌握情况。升级时按所有词表的 id 反查做一次性迁移，用 `StudyPreferences.statKeyVersion` 标记，查不到的键退化为小写保留而不是丢弃。
- **一句话说明代价**：这一版承认「答错照样能过」，但让敷衍变得不划算——5 分钟后就要再答一轮，且错词会一直回来找你。

相关代码：`feature/player/.../study/`（`QuizGate` 状态机、`QuizGenerator` 出题、`QuizOverlay` 浮层、`QuizSpeaker` 朗读）、`feature/settings/.../screens/parent/`（家长设置页）、`feature/settings/.../screens/report/`（学习报告页）、`core/model/.../StudyLedger.kt`（记账、归档与主键迁移）、`core/model/.../StudyReport.kt`（报表计算）、`core/data/.../QuizBankRepository.kt`（多词表加载）、`output/quiz-bank/gen_kebiao_primary.py`（课标二级词表生成与校验脚本）。

**题库扩充约定**：`confusables` 只能引用题库内已存在的词，禁止生造拼写（如 `fone`、`fourty`），否则孩子会在选项里看到不存在的英文单词。

## 构建与签名

**环境要求**

- Android SDK（已通过 `local.properties` 的 `sdk.dir` 指定）
- JDK 17 及以上
- 项目自带 Gradle Wrapper（无需单独安装 Gradle）

**调试构建**

```bash
./gradlew assembleDebug
```

**正式签名构建**

签名配置已从源码中移除，改由本地 `local.properties` 提供（该文件已被 `.gitignore` 忽略，不会进入仓库）。请在 `local.properties` 末尾追加：

```properties
tk.storeFile=../keystore/release.keystore
tk.storePassword=你的密码
tk.keyAlias=tongkan
tk.keyPassword=你的密码
```

> 未配置上述项时，`assembleRelease` 仍会生成**未签名**的 Release APK，方便开源协作；只有配置了签名信息才会产出正式签名包。

```bash
./gradlew assembleRelease
```

产物位于 `app/build/outputs/apk/release/`，包含按 ABI 拆分的包（armeabi-v7a / arm64-v8a / x86 / x86_64）及 `universal` 通用包。
